# Muhammad Jawad — Portfolio

A responsive personal portfolio built with **HTML, CSS and JavaScript**.

## Run it
1. Extract the ZIP file.
2. Open the `jawad-portfolio` folder in VS Code.
3. Open `index.html` in your browser, or use the VS Code Live Server extension.

## Important: personalize before publishing
Search the project files for `YOUR_EMAIL@jawad031788gmail.com` and replace it with your real email address.
In `index.html`, replace the LinkedIn `href="#"` with your real LinkedIn profile URL.
Replace the GitHub profile links on each project card with the direct repository URLs for those projects.
Only add a live demo link if that project is actually deployed.

## Files
- `index.html` — page structure and content
- `style.css` — responsive visual design
- `script.js` — mobile menu, scroll reveal, rotating role text and email form

The contact form opens the visitor's default email application. It does not send messages through a server.
